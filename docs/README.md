# OctoAcme Project Management Docs

This folder contains the OctoAcme project management process documents and serves as the single entrypoint for contributors and stakeholders to discover our project management artifacts.

## Summary of project management processes

OctoAcme runs projects iteratively from a clear initiation gate into planning and execution. Work begins with a Project One-pager (problem, goal, success metrics) and follows a lightweight initiation process that aligns stakeholders, defines scope, and clarifies ownership.

Planning then translates the initiative into a backlog, milestones, dependencies, and a delivery plan. Day-to-day execution centers on a project board (Backlog → Ready → In Progress → In Review → QA → Done) and a disciplined pull-request process: small PRs when possible, CI checks, and review before merge.

Quality, risk, and continuous improvement are integral. QA covers unit, integration, and end-to-end smoke tests where appropriate, plus CI security scanning and manual validation for acceptance. Risks are tracked and escalated through a clear communication cadence, and retrospectives turn learning into action items for the next cycle.
