# OctoAcme Project Management Docs

This folder contains OctoAcme's project management process documents. The README serves as a single entrypoint that briefly summarizes our approach and links to each process document.

## Project management processes (brief)
OctoAcme uses an iterative, customer-first approach with clear ownership and predictable rhythms. Key practices include:
- Regular team cadence: daily standups, weekly delivery syncs, and sprint demos
- Iterative planning and delivery: prioritized backlog, small increments, acceptance criteria
- Risk & dependency tracking: a simple risk register and clear escalation paths
- Continuous improvement: retrospectives with tracked action items and measurable follow-up
